# Частые вопросы (FAQ)

---

### Игра долго запускается при первом входе
При первом запуске лаунчер скачивает базовый клиент `1.21.1 NeoForge`, библиотеку ассетов и все моды сборки. Последующие запуски будут значительно быстрее.

### Ошибка авторизации или старый скин-сервер
Убедитесь, что вы вошли в аккаунт внутри лаунчера, а в папке с игрой нет сторонних модификаций авторизации. Лаунчер автоматически изолирует клиентский classpath.

### Не запускается игра на Windows (ошибка распаковки Java)
Откройте **Настройки** и повторно нажмите **Скачать Java 21**, либо укажите путь к уже установленной Java 21 (`java.exe`) вручную.
